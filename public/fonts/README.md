# Fonts Directory

Placez les fichiers de police Britti Sans dans ce dossier :

- `BrittiSans-Regular.woff2`
- `BrittiSans-Regular.woff`
- `BrittiSans-Bold.woff2`
- `BrittiSans-Bold.woff`

La police sera automatiquement chargée via les @font-face définis dans `LandingPage.vue`.

**Alternative** : Si vous n'avez pas les fichiers, Space Grotesk sera utilisée comme fallback (déjà chargée via Google Fonts).
